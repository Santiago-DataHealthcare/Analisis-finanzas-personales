# 💰 Análisis de Finanzas Personales con Python

Repositorio enfocado en el procesamiento, análisis exploratorio (EDA) y visualización de datos financieros personales para el control de gastos e ingresos.

---

## 🛠️ Tecnologías y Librerías Utilizadas
* **Lenguaje:** Python 🐍
* **Manipulación y Limpieza:** Pandas, NumPy
* **Visualización:** Matplotlib, Seaborn

---

## 📊 Descripción del Proyecto
Este proyecto procesa registros financieros para extraer métricas clave, detectar patrones de consumo por categorías y optimizar el seguimiento presupuestario mediante scripts modulares y limpios.

---

## Como ejecutar el proyecto localmente

1. Clona el repositorio con el siguiente comando:
git clone https://github.com/Santiago-DataHealthcare/analisis-finanzas-personales.git

2. Instala las librerias necesarias:
pip install pandas numpy matplotlib seaborn

3. Ejecuta el script principal o abre el entorno de Jupyter.
